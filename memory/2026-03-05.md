- ACP/acpx 配置踩坑：
  - 安装 `acpx` CLI（`npm i -g acpx`）并启用 OpenClaw 的 ACPX Runtime 插件。
  - OpenClaw 插件默认校验/本地 wrapper 在 Windows 上失败，需在 `~\.openclaw\openclaw.json` 中为 `plugins.entries.acpx.config.command` 指向全局 `acpx`，并将 `expectedVersion` 放宽（"any"）。
  - `acpx` 默认用 `npx @zed-industries/codex-acp` 作为 agent command 在 Node spawn 场景易失败（EINVAL/EPIPE）；需改 `~\.acpx\config.json` 的 `agents.codex.command` 直接指向 npx cache 中的 `codex-acp.exe`。
  - ACP turn 失败常因 non-interactive permission prompt 不可用导致 exec 被拒（`ACP_TURN_FAILED`/`acpx exited with code 5`）；为排障将 `~\.acpx\config.json` 的 `defaultPermissions` 调成 `approve-all`。
