# Naming & Storage Conventions

- Vault root: `D:\Notes`

## Note Types

### Daily / Journal
- Folder: `daily/`
- Filename: `YYYY-MM-DD.md`

### Copywriting (文案)
- Folder: `topics/文案/`
- Filename: `YYYY-MM-DD-HHMM-<slug>.md`
  - `<slug>`: 4–12 chars, Chinese allowed, remove `<>:"/\\|?*`.

### General quick note
- Folder: `inbox/`
- Filename: `YYYY-MM-DD-HHMM-<slug>.md`

## Keyword line
- Always directly under the first `# Title` line.
- Format: `关键词：#tag1 #tag2 #tag3 #tag4 #tag5 #tag6 #tag7`
